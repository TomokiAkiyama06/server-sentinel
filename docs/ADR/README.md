# Architecture Decision Records

Use ADRs for decisions that materially affect:
- protocol;
- storage;
- privacy;
- security;
- licensing;
- media transport;
- cross-component architecture.

Template:

```markdown
# ADR-NNNN: Title

Status: Proposed | Accepted | Superseded

## Context

## Decision

## Alternatives

## Consequences

## Validation

## Follow-up
```
