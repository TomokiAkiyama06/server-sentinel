# Web Dashboard

Planned stack:
- React
- TypeScript

Primary design target:
- mobile first.

Core views:
- status;
- live;
- events;
- recordings;
- Camera Node;
- presence/schedule;
- storage;
- Slack;
- audit;
- settings;
- setup/pairing.

Remote access is expected to be through the user's Tailscale deployment in MVP.
