# Events, Presence, and Timeline

Owns factual observations, source/confidence attribution, event-to-recording links, and presence states `PRESENT`, `PROBABLY_PRESENT`, `ABSENT`, and `UNKNOWN`.

Manual override takes precedence; only explicit/high-confidence `PRESENT` suppresses ordinary occupancy automation by default. Movement/tamper remain armed in every state. Historical events/timeline require `recordings:view`; do not infer culprit identity, guilt, or causality.
